### 3.1 est_pop に pop_tan と同じ値を入れた場合（コードから確定する帰結）

- #1 と #2 の加減点がすべて 0 になる。
- #4 は推定1位＝1番人気となり、常に −8 になる。
- #5 の過剰人気は常に 0 頭、#6 の勝負所条件③は常に不成立になる。したがって **⚡勝負所は一度も出なくなる**。
- アドendum §6 の前提「pop_tan とは別の指標でなければならない」は、上記によりコード上で裏付けられる。

## 4. 段階Bで入力を自動生成するときの注意（コードから確定する事実のみ）

1. **単勝1番人気の odds が空だと荒れスコアが −8 される。** `parseFloat("") || 0` が 0 になり、`o > 0 && o < 2.5` は不成立、続く `o < 3.5` が成立して「1番人気が堅い(<3.5倍)」扱いになる（1609〜1617 行）。export では1番人気の単勝オッズを必ず埋める必要がある。
2. **est_pop・pop_tan が空の馬は判定から消える。** 全頭入力の原則を export でも守るには、両方を全頭で埋める必要がある。
3. **rank の欠損は C 扱い（+8 点）になる。** JRA-VAN に rank 相当の値は無い（2026-10-12 決定 Q1）。段階Bでは est_pop の代替値から固定の変換表で作る。
4. **小系統・騎手名・種牡馬名は表記の完全一致で効く。** 表記がずれると内部タイプ `other`、または0点になり、エラーは出ない。
