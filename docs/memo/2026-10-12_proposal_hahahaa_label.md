## 現状

`index.html`（main 4434551 時点）3111 行目の入力欄ラベル:

```
B層：母母父小系統（SmartRc「父母父小系統」欄）
```

## 問題

- キー名 `hahahaa_kei` とコードのコメント（「B層：母母父小系統（隔世遺伝）」、`calcB_MotherLine` B-2）は**母母父**を指している。
- Q4 の決定により、入力すべき値は**母母父**で確定した。SmartRc の血統系統画面には父母父と母母父が別の列で存在する。
- ラベルの「父母父小系統」欄を見て入力すると、別の血統位置の値が入る恐れがある。

## 提案

ラベルの文字列だけを次のように直す。

```
B層：母母父小系統（SmartRc「母母父小系統」欄）
```

## 影響範囲

- 表示文字列のみ。キー名・スキーマ・判定ロジック・閾値には影響しない。
- SmartRc 側の列名が「母母父小系統」かどうかは、修正時に画面で確認する。

## 実装する場合の手順

1. 本提案を人が承認する。
2. `feature/*` ブランチで index.html の該当文字列だけを変更する。
3. `npm run check` と `npm test` を通し、PR を作成する。main へのマージは人が行う。
