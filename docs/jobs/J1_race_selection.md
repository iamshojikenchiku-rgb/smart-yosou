# J1 — 週末の候補レース選定（木 21:00 JST・定時）

## 目的
今週末（土・日）に検討する **候補レースを1〜2件**、出典付きで提示する。人は金曜までに「承認／差替」し、承認レースのスクショを投入する。

## 入力
- `docs/jobs/README.md`（共通セットアップ・共通ルール）
- `index.html` の `ARERU_RACES`（荒れやすいレース一覧・備考・caution）— `node -e` で読むか `docs/設計アドendum_G層π参考値_v0.1.md` §1 を参照
- `docs/operation_flow_definition.md` §2 ステップ2（選定基準）
- `data/ledger.json` → `node scripts/ledger.js summary`（月内残額）
- プロジェクト知識 `戦略見直し検討メモ v0.1`（ねじれ仮説・観察対象）
- **Web検索**: 当週末の JRA 開催日程・重賞／OP 一覧（JRA公式または信頼できる競馬メディア）

## 手順
1. 共通セットアップを実行し、`npm run ledger -- summary` で今月の残額を把握する。残額が 500 円未満なら「今週は見送り（予算）」として終了。
2. Web検索で **今週末の日付と開催場・重賞／OP** を確認する。検索で確認できたものだけを候補にする。**開催日程の記憶は使わない**。
3. 候補の優先順位（運用フロー定義書 §2 ステップ2）:
   1. `ARERU_RACES` 該当（caution 行は減点し、原則候補にしない）
   2. ハンデ戦 / 小回り・ローカル（札幌・函館・福島・小倉・新潟内回り）/ 道悪予報
   3. G3・混戦（1番人気が固くない見込み）
   4. 残額に応じて 1〜2 レースに絞る（原則 週 2,500 円以内）
4. 各候補について、日程の出典URL・コース・距離・馬場種別・想定 `courseType`（big_turf / small_turf / dirt 等）・選定理由（上記のどれに該当するか）を書く。
5. 「観察のみ（購入しない）」の枠として、市場が堅いと見ている重賞を 1 件まで併記してよい（ねじれサンプル蓄積のため）。買い目は出さない。

## 出力
プロジェクト知識 `claude/weekly/YYYY-MM-DD_候補.md`（YYYY-MM-DD は土曜の日付）:

```
# 候補レース（YYYY-MM-DD 週）
## 予算
- 今月残額: ○○円 / 今週上限: 2,500円
## 候補
1. <レース名>（<日付> <場> <芝/ダ><距離>m <クラス> <ハンデ有無>）
   - 選定理由: ARERU_RACES該当（備考: …）／ハンデ／小回り …
   - 想定 courseType: small_turf
   - 出典: <URL>
2. …
## 観察のみ（購入しない）
- <レース名> … 出典: <URL>
## 人への依頼
- 承認するレースの「出馬表・血統・推定人気（SmartRc）・複勝オッズ」のスクショを、
  金曜夜までに `YYYYMMDD_<レース名>_<種別>_<連番>.png` の名前でプロジェクトに追加してください。
```

## 終了条件・禁止
- 出典URLの無い候補は書かない。検索で日程を確認できなかった場合は「未確認のため候補なし」で終了する。
- 買い目・馬名の推奨は **J1では書かない**（J2 の役割）。
