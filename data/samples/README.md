# data/samples — G層π参考値バックテスト用サンプル

`npm run backtest` は既定でこのディレクトリの `*.json` を全て読む。

## ファイルの種類

| 種類 | 目印 | 集計 | 説明 |
|:--|:--|:--|:--|
| 完全版 | （目印なし） | 対象 | ツールの「保存済みレース → 結果 → JSONをコピー」で出力したもの。**正本はこれ** |
| 遡及・部分 | `"partial": true` | 各層スコアが無いため対象外（読込・件数には出る） | 設計文書に記録のある事実だけを手入力したもの。完全版に差し替え予定 |
| 合成 | `"synthetic": true` | 既定では除外。`--include-synthetic` で含める | パイプライン検証用の架空データ。**実レースではない**。成績の解釈に使わない |

## 追加手順（週次運用 ステップ7）

1. ツールでレースを保存し、レース後に「結果」から 1〜3着・開催日・確定馬場を入力。
2. 「保存済みレース」画面上部の「JSONをコピー」→ `data/samples/YYYY-MM-DD_<レース名>.json` として保存
   （配列のまま保存してよい。1ファイル複数レース可）。
3. `npm run backtest` を実行。10レース未満の間は結論を出さない（§3.3）。

## 遡及入力の状況（2026-09-05）

設計アドendum §3.1 が挙げる過去レース（オークス・しらさぎS・日本ダービー・安田記念・宝塚記念）のうち、
リポジトリ内／プロジェクト文書に**結果と血統の事実が文書化されているのは オークス（2026-05-24）と しらさぎS（2026-06-21）の2件のみ**。
両者とも全頭の入力JSON・各層スコア・複勝オッズは文書に無いため `partial` として収録した。
日本ダービー・安田記念・宝塚記念は文書化されたデータが無く、**推測での作成はしていない**（運用フロー定義書「確定着順・確定馬場は推測しない」）。
当時の入力JSONが手元にあれば、ツールに読込→結果入力→エクスポートで完全版を作成できる。
